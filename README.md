## 🎮 How to Use (CLI)

**Main Menu**
```
[1-15]  Open a phase
[r]     View your profile & rank
[s]     Search topics/tools
[b]     Manage bookmarks
[p]     View progress report
[a]     View badges earned
[c]     CTF Challenge mode
[t]     Change theme (dark/light)
[0]     Exit
```

**Phase Menu**
```
[v]     Watch phase playlist
[1-N]   Open topic
[0]     Back
```

**Topic Menu**
```
[1]     View & open tools
[2]     Watch tutorial (if available)
[b]     Add/remove bookmark
[d]     Mark topic done/undone
[0]     Back
```

## 🐛 Troubleshooting

**Files not found**
→ Keep all files in the same folder

**Links not opening**
→ Check internet connection

**Colors not showing**
→ Use a modern terminal / try `[t]` to switch theme

**Termux users**
→ `pkg install python` then `python main.py`
